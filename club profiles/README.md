# ECHO//SHARE Club Profiles

Edit `club-profiles.js` to add clubs.

Search format:
- `club/example-club`
- `club example-club`

Each club supports:
- name
- id
- image
- background
- music (from the main `sounds/` folder)
- followers
- supports
- badge (optional; use `""` or `null` to remove it)
- tags
- bio
- status
- glow
