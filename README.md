# ECHO//SHARE CHAT_90 — Quality Update

This build preserves the existing CHAT_90 design and adds:
- One MEDIA button that opens the device file picker for images, GIFs, and videos.
- Replies to messages.
- Custom GIF reactions through the device file picker.
- Special-account Discord-style profile banners.
- Larger, richer profile cards.
- STAR-MID starlight VFX with a white aura, stars, glowing chat area, and mini star after messages.
- Stronger special-account visual effects.
- Instant special-profile/effect updates broadcast to everyone and applied to past messages.
- Profile/reaction/media data is persisted by the CHAT_90 server.

Upload the frontend and backend files to the same GitHub repository/branch used by Render.

Media limits:
- Shared image/GIF/video: 8 MB per file.
- GIF reaction: 4 MB per file.
- Special profile banner: 3 MB per file.
